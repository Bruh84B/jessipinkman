Синхронизация через GitHub

Заметки хранятся в твоём приватном репозитории. Каждое устройство отправляет туда изменения и забирает чужие — сами, в фоне.

  1. Создай приватный репозиторий, например mindbutter-notes: github.com/new
  2. Создай токен: новый токен. Repository access → Only select repositories → этот репозиторий. Permissions → Contents → Read and write.
  3. Вставь репозиторий и токен ниже. На втором устройстве — то же самое.

Токен хранится только в этом браузере и открывает доступ только к выбранному репозиторию. Если одну заметку изменили на двух устройствах, обе версии сохранятся.
