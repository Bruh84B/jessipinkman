# MindButter

Заметки в обычных файлах markdown, связанные ссылками. По механике похоже на Obsidian:
`[[ссылки]]`, обратные ссылки, теги, граф связей, быстрый переход. Без сервера, без сборки,
без регистрации — набор статичных файлов.

## Запуск

**На компьютере, без интернета.** Открой `index.html` двойным кликом в Chrome, Edge или Яндекс Браузере.

**Через локальный сервер** (нужен, чтобы работал офлайн-режим и установка как приложение):

```
python -m http.server 8000
```

и открой http://localhost:8000.

**Через GitHub Pages.**
1. Репозиторий с этими файлами уже есть на GitHub.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)` → Save.
3. Через минуту приложение откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Где хранятся заметки

При первом запуске MindButter спрашивает, где хранить заметки:

| Способ | Где работает | Что важно |
|---|---|---|
| **Папка на компьютере** | Chrome, Edge, Яндекс Браузер на компьютере | Заметки — настоящие `.md` файлы. Подходит существующая папка Obsidian (служебную `.obsidian` MindButter не трогает). |
| **В браузере** | Везде, включая телефон | Заметки живут в IndexedDB этого браузера. Очистка данных сайта их сотрёт — периодически скачивай архив (меню хранилища → «Скачать всё в zip»). |

На GitHub заметки **не** отправляются, даже если приложение открыто с GitHub Pages.
Чтобы хранить заметки в git — выбери «Папка на компьютере» и укажи папку репозитория.

## Что умеет

- `[[Заметка]]`, `[[Заметка|свой текст]]`, `[[Заметка#Заголовок]]`, вложение `![[Заметка]]` и `![[картинка.png|300]]`.
- Подсказка названий при вводе `[[`, автозакрытие скобок, Ctrl+клик по ссылке в режиме правки.
- Клик по несуществующей ссылке создаёт заметку.
- Переименование и перенос (в том числе перетаскиванием в дереве) переписывают ссылки во всех заметках.
- Обратные ссылки, упоминания без ссылки, исходящие ссылки, оглавление.
- Теги `#тег` и `#вложенный/тег`, теги из frontmatter (`tags:`), панель тегов.
- Полнотекстовый поиск, быстрый переход (Ctrl+O), заметка на сегодня.
- Граф: весь или вокруг заметки, теги и несозданные заметки точками, масштаб и перетаскивание.
- Режим чтения: таблицы, задачи с галочками, выноски `> [!note]`, `==выделение==`.
- Вставка картинок из буфера или перетаскиванием — сохраняются в папку `Вложения`.
- Светлая и тёмная тема, работа на телефоне, офлайн после первого открытия.

## Инструкция с картинками и озвучкой

Открывается сама при первом запуске и по кнопке «?» в ленте слева: 7 шагов, у каждого простая картинка
и кнопка «Послушать».

**Озвучка.** По умолчанию текст читает голос самого браузера — бесплатно, без настройки, но звучит
по-разному на разных устройствах. Чтобы был живой голос (например, из ElevenLabs), положи файлы
`guide/1.mp3` … `guide/7.mp3` — приложение возьмёт их вместо голоса браузера. Тексты для записи —
поле `say` у каждого шага в `guide.js`.

## Горячие клавиши

На Mac вместо Ctrl — Cmd.

| | |
|---|---|
| Ctrl+O | быстрый переход |
| Ctrl+N | новая заметка |
| Ctrl+E | чтение ↔ правка |
| Ctrl+G | граф |
| Ctrl+Shift+F | поиск |
| Alt+← / Alt+→ | назад / вперёд |
| Ctrl+B / Ctrl+I | жирный / курсив |
| Ctrl+S | сохранить сейчас (сохраняется и само) |

## Чего нет (честно)

- Нет «живого» оформления прямо при наборе: два режима, правка и чтение.
- Нет плагинов, синхронизации между устройствами, вкладок и разделения окна.
- Удаление окончательное, корзины нет.
- Режим «папка на компьютере» — только браузеры на движке Chromium.

## Устройство

| Файл | Что внутри |
|---|---|
| `index.html` | разметка |
| `style.css` | оформление, темы, телефонная раскладка |
| `store.js` | хранилища (браузер / папка), экспорт в zip |
| `md.js` | разбор ссылок и тегов, поиск файла по ссылке, рендер markdown |
| `graph.js` | граф на canvas со своей физикой |
| `guide.js` | инструкция: шаги, картинки, озвучка |
| `app.js` | интерфейс |
| `sw.js` | офлайн-режим |
| `vendor/` | [marked](https://github.com/markedjs/marked) (MIT) и [DOMPurify](https://github.com/cure53/DOMPurify) (Apache-2.0 / MPL-2.0), лицензии рядом |

**Выпуск обновления:** подними номер `?v=3` у файлов в `index.html` и в списке `ASSETS` в `sw.js`,
а также `CACHE` в `sw.js`. Иначе браузер может показать старую версию из кеша. Это важно и потому,
что у всех проектов на `<логин>.github.io` общий адрес сайта, а у других проектов там может быть
свой service worker.
